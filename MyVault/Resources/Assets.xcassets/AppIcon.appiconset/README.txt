# App Icon — MyVault
# Concept: minimal vault shield + photo motif, deep navy gradient with gold lock.
#
# To generate the final 1024x1024 App Store icon:
# 1. Open MyVault/Resources/AppIcon/IconConcept.svg (reference) in Figma/Sketch.
# 2. Export a 1024x1024 PNG named AppIcon-1024.png with no transparency.
# 3. Place it at MyVault/Resources/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png
# 4. In Xcode, select the AppIcon asset and verify all slots resolve from the 1024 source.
# 5. Do not use copyrighted logos. Keep contrast ratio >= 4.5:1 for the lock glyph.
